# RemotePilot 3DS PC tool

Run `run.cmd` on Windows, or `python3 receiver.py serve`. Open http://127.0.0.1:38764/.

See [the setup guide](../docs/SETUP.md). This copy includes the following presets: example, homebrew. Pairing data stays in ignored `local/`.
