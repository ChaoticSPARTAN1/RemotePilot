# RemotePilot PSP: PC viewer

The RemotePilot viewer with the PSP section: the **PSP · Homebrew
(RemotePilot PSP)** preset (a template for any PSP build that answers RP2), a PSP-1000-style device view with its controls, live view and screen
capture over the PSP's Wi-Fi, device logs, and a read-only **PSP folders**
browser for the Memory Stick, and the **PSP settings backup**. **Options → Write a
bug report** saves a report (with the device's screen and log, if you choose) in
`local/bug-reports/` on this computer only; nothing is sent to GitHub or
anywhere else.

Start it with `run.cmd` (Windows) or `sh run.sh`. See [../README.md](../README.md)
for the device side, pairing and limits.
